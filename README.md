## Task 2: Research & Configure

### What I Did
I researched best practices for guiding AI coding assistants and created a rules file
to control how the agent interacts with me. The rules focus on clarity, learning,
and safe coding practices.

### What Worked
- The AI provided clearer explanations.
- Responses were more step-by-step instead of assuming prior knowledge.
- The agent followed a simpler coding style.

### What Didn’t Work
- Some responses were still more detailed than necessary.
- The AI occasionally suggested advanced concepts.

### What I Learned
Providing explicit instructions helps shape AI behavior.
Clear constraints and learning-focused rules improve usability,
especially for beginners.
